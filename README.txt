FuturePath SA interactive mockup v2

How to run on Windows:
1. Extract the ZIP file.
2. Open the futurepath_sa_site_v2 folder.
3. Double-click index.html.

This version is a single self-contained HTML file. The CSS and JavaScript are inside index.html, so it should not break because of missing linked files.

Included mock sections:
- Home
- Check Results with mock APS calculator
- OCR upload placeholder
- Industry Pathways
- Career Explorer
- Course Finder
- Institution Finder
- Bursary Matcher
- Application Planner
- Parent Mode
- Offline / Low-Data Access

All data is mock data for design and concept demonstration.
